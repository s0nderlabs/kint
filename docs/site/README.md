# kint documentation

The chapters of kint's documentation site, one markdown file each. They render as static pages
through `scripts/build_docs.py`; links of the form `/docs/<page>` inside them resolve on the site,
not on GitHub. Start with the Quickstart if you are installing, or with For agents if an AI agent
is doing the install for you.
